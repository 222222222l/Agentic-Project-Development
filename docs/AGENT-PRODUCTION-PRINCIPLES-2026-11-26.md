# 通用 Agent 生产与组织工程增量计划

日期：2026-11-26。来源：用户确认的八项架构原则。适用于软件、研究、工业与其他 Agent 任务，无游戏专有假设。外部案例是设计动机，本仓库效果须实测。

## 通用范式

P01 依赖决定并行度；P02 关键路径有序、无冲突分支并行；P03 根据任务拓扑、风险和可验证性选择组织形态；P04 先冻结意图、输入版本、读写资源、输出、权限、oracle、预算及停止条件，再生产；P05 worker 提交，独立 verifier 绑定产物版本验证；P06 复用语义、工具和流程契约，宿主特有实现保留原生交付；P07 持久任务状态、事件与证据，有限重试、幂等、对账、人工接管；P08 优化独立验收合格产出的全成本和新需求验证周期，重复任务是基线。
